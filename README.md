One funny line from a hopeless tech support agent to a desperate customer,
written to `entry.txt` by `main.ts`:

> My laminated flowchart covers this exact fault in twelve steps — step one is 'turn to page two', and page two is missing.

The agent's only tool is a laminated flowchart — twelve steps of total
confidence — and the page that would actually help is the one that's
missing. Cheerful, useless, and never the customer's fault.
